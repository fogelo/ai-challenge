# MCP Integration Design

**Дата:** 2026-03-09
**Статус:** Утверждено

## Обзор

Интеграция MCP (Model Context Protocol) клиента в существующий CLI агент. Задание дня 16: установить MCP соединение и получить список доступных инструментов.

## Цели

- Добавить MCP клиент в CLI агент
- Поднять локальный MCP сервер с тестовыми инструментами
- Реализовать команду `/mcp` для подключения и вывода списка инструментов

## Архитектура

### Новые файлы

```
src/mcp/
├── server.ts       # MCP сервер с тестовыми инструментами (запускается как отдельный процесс)
├── client.ts       # MCPClientManager — управление соединением
└── index.ts        # экспорты
```

### Транспорт

Stdio транспорт — сервер запускается как дочерний процесс через `StdioClientTransport` из `@modelcontextprotocol/sdk`. Это каноничный способ работы локальных MCP серверов.

### Поток данных

```
Пользователь → /mcp
  → MCPClientManager.connect()
    → spawn: node dist/mcp/server.js
    → StdioClientTransport
    → client.listTools()
  → список инструментов отображается в Chat UI
```

## Компоненты

### MCP Сервер (`src/mcp/server.ts`)

Три тестовых инструмента:

| Инструмент | Описание | Параметры |
|---|---|---|
| `get_time` | Возвращает текущее время | — |
| `echo` | Повторяет переданный текст | `message: string` |
| `get_agent_info` | Информация об агенте (версия, платформа) | — |

### MCP Клиент (`src/mcp/client.ts`)

Класс `MCPClientManager`:
- `connect()` — запускает сервер как дочерний процесс, устанавливает соединение
- `listTools()` — возвращает список инструментов
- `disconnect()` — закрывает соединение и процесс
- `isConnected()` — статус соединения

### Команды в Chat.tsx

| Команда | Действие |
|---|---|
| `/mcp` | Подключиться (если не подключён) и показать список инструментов |
| `/mcp disconnect` | Отключиться от сервера |
