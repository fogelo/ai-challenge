# Инструкции по тестированию Context Strategies

## Предварительные требования

1. Установите зависимости: `npm install`
2. Соберите проект: `npm run build`
3. Убедитесь что OPENROUTER_API_KEY настроен в .env

## Тест 1: Sliding Window Strategy

```bash
npm start
```

Команды для тестирования:
```
/strategy
/strategy 1
Привет, это тестовое сообщение 1
Тестовое сообщение 2
Тестовое сообщение 3
```

**Ожидаемый результат:**
- ✓ Стратегия переключается на "Sliding Window"
- ✓ Сообщения добавляются в историю
- ✓ LLM отвечает корректно

## Тест 2: Sticky Facts Strategy

Команды:
```
/strategy 2
Моя цель - создать веб-приложение
Я предпочитаю использовать React
Мой бюджет составляет $5000
/facts
```

**Ожидаемый результат:**
- ✓ Стратегия переключается на "Sticky Facts"
- ✓ После каждого сообщения пользователя извлекаются факты
- ✓ Команда `/facts` показывает JSON с извлечёнными фактами:
  - goal: "создать веб-приложение"
  - preferences: "React"
  - constraints: "$5000"

## Тест 3: Branching Strategy

Команды:
```
/strategy 3
Сообщение 1 в основной ветке
Сообщение 2 в основной ветке
/checkpoint
/branch new Вариант А
Сообщение в ветке А
/branch new Вариант Б
Сообщение в ветке Б
/branch list
/branch 1
Ещё одно сообщение в ветке А
/branch main
```

**Ожидаемый результат:**
- ✓ Чекпойнт создаётся успешно
- ✓ Создаются две ветки: "Вариант А" и "Вариант Б"
- ✓ `/branch list` показывает все ветки и чекпойнты
- ✓ Переключение между ветками работает
- ✓ Возврат на main ветку работает

## Тест 4: Session Save/Restore

Команды:
```
/strategy 2
Сообщение для сохранения
/facts
<Ctrl+C для выхода>

npm start
/resume 1
/facts
```

**Ожидаемый результат:**
- ✓ Сессия сохраняется с состоянием стратегии
- ✓ При resume восстанавливается Sticky Facts стратегия
- ✓ Извлечённые факты сохраняются между сессиями

## Тест 5: Переключение стратегий с сохранением сообщений

Команды:
```
/strategy 1
Сообщение 1
Сообщение 2
/strategy 2
Продолжение диалога
/facts
```

**Ожидаемый результат:**
- ✓ При переключении стратегии все сообщения переносятся
- ✓ История сохраняется
- ✓ Новая стратегия получает доступ ко всем предыдущим сообщениям

## Известные ограничения

1. **Sticky Facts:** Дополнительные API вызовы для извлечения фактов увеличивают стоимость
2. **Branching:** Требует ручного управления чекпойнтами
3. **Все стратегии:** Нет автоматической миграции существующих сессий
