# Demo: MCP Integration

## Запуск

```bash
npm start
```

## Сценарий демонстрации

### 1. Показать список команд
```
/help
```
Убедиться, что в секции 📡 MCP видны команды `/mcp` и `/mcp disconnect`.

---

### 2. Подключиться к MCP серверу и получить список инструментов
```
/mcp
```
**Ожидаемый результат:**
```
✅ MCP сервер подключён

Доступные инструменты (3):

🔧 get_time
   Возвращает текущее дату и время

🔧 echo
   Повторяет переданное сообщение

🔧 get_agent_info
   Возвращает информацию о CLI агенте
```

---

### 3. Повторный вызов (переиспользование соединения)
```
/mcp
```
Список показывается снова без повторного запуска процесса.

---

### 4. Отключиться
```
/mcp disconnect
```
**Ожидаемый результат:**
```
🔌 MCP отключён
```

---

### 5. Снова подключиться (новое соединение)
```
/mcp
```
Сервер запускается заново, список инструментов снова отображается.

---

## Что демонстрирует

- MCP соединение устанавливается через stdio транспорт
- Сервер запускается как дочерний процесс
- `listTools()` возвращает схему инструментов
- Соединение корректно закрывается
