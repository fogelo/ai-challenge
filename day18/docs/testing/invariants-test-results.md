## Статус реализации

### ✅ Реализовано
- InvariantStorage (загрузка/сохранение JSON)
- InvariantValidator (LLM валидация)
- InvariantInjector (форматирование для промпта)
- InvariantManager (координатор)
- Интеграция в Chat.tsx (загрузка, инжекция в промпт, валидация ответов)
- Команды /invariants (show, reload, test)
- Автоматическое создание дефолтного файла

### 📝 Ограничения окружения
- Приложение не может быть полностью протестировано в CI/неинтерактивном режиме
- Ink требует интерактивный терминал (raw mode)
- Тесты должны быть выполнены пользователем при реальном запуске

### 🎯 Инструкции для пользователя
1. Запустить: `npm start`
2. Проверить автоматическое создание `.invariants/default.json`
3. Выполнить: `/invariants` - должен показать список инвариантов
4. Выполнить: `/invariants test Напиши компонент на jQuery` - должен показать нарушение
5. Выполнить: `/invariants test Напиши функциональный компонент` - должен пройти
6. Попробовать реальный запрос с нарушением инвариантов
7. Отредактировать `.invariants/default.json` и выполнить `/invariants reload`
